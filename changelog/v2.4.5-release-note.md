# v2.4.5 Release Note

## Summary

v2.4.5 is a small maintenance patch on top of v2.4.4, containing a single Go change in the action pool. No hardfork, no genesis change, and no config schema change — v2.4.5 introduces no new activation heights, and the code is identical to v2.4.5-rc0.

## Changes

### Fix

- **actpool: fix a hash handling edge case** — tightens a lookup in the action pool's duplicate-action fast path. Behavior for normal traffic is unchanged.

## Upgrade Priority

v2.4.5 is **recommended** for all node types.

| Node type     | Action            |
| ------------- | ----------------- |
| Delegate      | **Recommended**   |
| Fullnode      | **Recommended**   |
| API node      | **Recommended**   |
| Archive node  | **Recommended**   |

No genesis or config schema changes are required; v2.4.5 is Go-only and introduces no new activation heights. No database migration, resync, or snapshot reload is needed — upgrading is a straight image swap from v2.4.4.
